# spring-coding

## 适用约定

- 根据任务确认涉及的类是新建还是已有，并查看项目明确的编码规范及现有 Lombok 使用方式。
- 项目明确规定的规范优先于本技能的默认约定；历史代码中的字段注入写法本身不构成新类继续使用字段注入的要求。
- 技术方案涉及 Spring 类的依赖设计或示例代码时，同样应用以下规则。

## 依赖注入

- 新建 Spring 管理的类时，依赖统一使用构造器注入，依赖字段优先声明为 `private final`；不使用字段注入。
- 修改已有类时，遵循该类现有的依赖注入方式；仅在明确要求迁移，或当前改动确有必要时，调整其注入方式。
- 构造器使用显式声明还是项目现有的 Lombok 写法，遵循项目约定；不为实现构造器注入额外引入依赖。
